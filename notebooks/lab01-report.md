## 6. Гипотезы о признаках (шаг 6)

### Гипотеза 1 (физическая): `Weight ∝ Length3 · Height · Width`

- Признак `V_approx = Length3 · Height · Width` рассчитан **без использования `Weight`** → утечки нет.
- Pearson r (log-log) = **0.991**; Spearman r = **0.983**; R² ≈ 0.98.
- **Заключение:** гипотеза подтверждена. `V_approx` может подаваться в модель как независимый признак.

### Гипотеза 2 (категориальная): `Species` кодируется One-Hot

- `OneHotEncoder(handle_unknown="ignore")` для нового вида возвращает вектор из нулей → модель не падает, но выдаёт усреднённое предсказание.
- **Заключение:** One-Hot корректен; неизвестный вид нужно логировать и, при повторении, добавлять в обучающую выборку.

### Гипотеза 3 (техническая): длины мультиколлинеарны

- Попарные корреляции: Length1–Length2 = 0.9995, Length1–Length3 = 0.9920, Length2–Length3 = 0.9941.
- VIF: Length1 = 1331.6, Length2 = 1797.6, Length3 = 109.2.
- **Заключение:** для линейных моделей достаточно одной длины (например, `Length3`) либо агрегата `L_mean`. Для деревьев и бустинга дублирование не критично. Автоматическое удаление по порогу корреляции не выполняем без отдельного обоснования — короткие и длинные рыбы могут реагировать на длину по-разному.

## 7. Разбиение и проверка утечек (шаг 7)

**Правило разбиения:**
- Стратификация по `Species`.
- Соотношение 60 / 20 / 20.
- `random_state = 42`.
- Единица наблюдения — одна рыба; групп нет (при появлении — `GroupShuffleSplit`).

**Размеры выборок:**

| Часть | Размер | Доля |
|---|---|---|
| Train | 94 | 59% |
| Val | 32 | 20% |
| Test | 32 | 20% |

**Ассерты:**

- `train ∩ val = ∅`, `train ∩ test = ∅`, `val ∩ test = ∅`.
- `V_approx = Length3 · Height · Width` — без `Weight`.
- `Weight ∉ признаки` (`Species, Length1..3, Height, Width, V_approx`).

Все ассерты пройдены.

**Таблица каналов утечки:**

| № | Канал утечки | Как проявляется | Как предотвратить |
|---|---|---|---|
| 1 | Статистики всей таблицы | Скейлер посчитан до split → val/test видны в train | `fit` только на train, `transform` на val/test |
| 2 | Повторные строки | Один объект в train и test | `drop_duplicates` до split; при повторах измерений — группировка |
| 3 | Идентификатор (`Id`, индекс) | Модель запоминает строку по номеру | Удалить Id и индекс из признаков |
| 4 | Постфактум-измерение | Признак известен только после целевого события | Проверить причинно-временную доступность признака |
| 5 | Ручной подбор по test | Гиперпараметры подобраны по test | Подбор — на val; test используется один раз в конце |
| 6 | Целевая в признаках | Новый признак построен из `Weight` | `V_approx = L3 · H · W` строится без `Weight` |
